# Projeto — Landing Page Vanderlei Oliveira Imóveis

## Visão Geral

Este projeto consiste no desenvolvimento de uma landing page institucional premium para o corretor de imóveis Vanderlei Oliveira, com foco em autoridade, confiança, presença digital profissional e geração de contatos via WhatsApp.

A landing page deve transmitir sofisticação visual, credibilidade e atendimento profissional, mantendo uma comunicação acessível para diferentes públicos do mercado imobiliário.

O site será desenvolvido utilizando Next.js, Tailwind CSS e design totalmente responsivo.

---

# Objetivos do Projeto

- Criar uma presença digital moderna e profissional
- Gerar contatos qualificados via WhatsApp
- Transmitir autoridade e confiança
- Valorizar a imagem profissional do corretor
- Melhorar percepção de marca pessoal
- Criar uma experiência visual premium
- Diferenciar o cliente de sites imobiliários genéricos

---

# Sobre o Cliente

Nome:
Vanderlei Oliveira

Segmento:
Mercado imobiliário

Atuação:
Compra, venda e intermediação de imóveis em Sergipe.

O cliente atende diferentes perfis de público:
- imóveis populares
- imóveis residenciais
- imóveis comerciais
- imóveis de médio padrão
- imóveis de alto padrão

A comunicação do site não deve limitar o público apenas ao mercado de luxo.
