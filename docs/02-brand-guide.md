# Brand Guide — Vanderlei Oliveira Imóveis

# Direção da Marca

A marca deve transmitir:

- autoridade
- confiança
- sofisticação
- segurança
- profissionalismo
- elegância
- credibilidade
- modernidade

A comunicação visual deve passar sensação premium sem parecer exageradamente luxuosa ou distante.

O objetivo é transmitir:
"profissional de confiança com presença forte no mercado imobiliário".

---

# Estilo Visual

A direção visual do projeto será:

- dark premium
- elegante
- minimalista
- sofisticada
- moderna
- refinada
- cinematográfica

O site NÃO deve parecer:
- template genérico
- site WordPress antigo
- imobiliária comum
- layout poluído
- design datado

Sensação Visual

impacto visual

O visual deve lembrar:

marcas premium

páginas de luxo minimalistas
Tipografia

O projeto deve utilizar tipografia moderna, limpa e sofisticada.

Sugestões:

Poppins
Inter

Regras:

títulos fortes
excelente legibilidade
espaçamento confortável
aparência moderna
hierarquia visual clara
Imagens

As imagens devem seguir padrão premium.

Utilizar:

imóveis modernos
arquitetura sofisticada
ambientes elegantes
imagens cinematográficas
iluminação refinada
composições modernas

Evitar:

imagens genéricas
baixa qualidade
aparência artificial exagerada
excesso de elementos
Hero Section

A primeira dobra deve conter:

imagem de fundo ocupando toda a tela
overlay preto escuro
textos no lado esquerdo
foto recortada do corretor no lado direito
CTA forte para WhatsApp
detalhes dourados

A hero section deve causar forte impacto visual.

Botões

Os botões devem ter aparência premium.

Características:

cantos arredondados
animações suaves
efeito hover elegante
destaque visual sofisticado
excelente contraste

Botão principal:

fundo dourado
texto preto

Botão secundário:

fundo transparente
borda dourada
texto branco
Espaçamento e Layout

O layout deve respirar.

Utilizar:

espaçamentos amplos
grids organizados
alinhamentos refinados
seções bem separadas
composição moderna

Evitar:

poluição visual
excesso de texto
excesso de cores
excesso de elementos
Responsividade

A versão mobile é extremamente importante.

O site deve:

funcionar perfeitamente no celular
manter aparência premium no mobile
preservar hierarquia visual
ter excelente leitura
manter espaçamentos organizados

O design mobile NÃO deve parecer uma adaptação simples do desktop.
O mobile deve parecer projetado especificamente para celular.
