# Regras Obrigatórias para o Codex

# Objetivo

Criar uma landing page premium, sofisticada, moderna e altamente profissional para Wanderley Oliveira Imóveis.

O resultado deve parecer um projeto de agência premium moderna.

---

# Tecnologias Obrigatórias

Utilizar:

- Next.js
- React
- Tailwind CSS
- TypeScript

---

# Responsividade

A responsividade é extremamente importante.

A versão mobile NÃO pode parecer apenas uma adaptação simples do desktop.

O mobile deve:
- parecer premium
- ter excelente espaçamento
- ótima leitura
- hierarquia visual clara
- excelente experiência visual

---

# Hero Section

A primeira dobra deve obrigatoriamente conter:

- imagem de fundo full screen
- overlay preto escuro
- textos alinhados à esquerda
- foto recortada do corretor à direita
- botões CTA
- visual cinematográfico
- estética premium

A hero section deve causar forte impacto visual.

---

# Direção Visual

O site deve ser:

- moderno
- sofisticado
- elegante
- premium
- minimalista
- refinado
- cinematográfico

O site NÃO deve parecer:
- WordPress antigo
- template genérico
- site poluído
- layout simples demais
- design ultrapassado

---

# Paleta de Cores

Preto:
#000000

Dourado:
#D1AF66

Branco:
#FFFFFF

---

# Regras de Layout

Utilizar:
- grids modernos
- bastante respiro visual
- espaçamentos amplos
- alinhamentos refinados
- composição sofisticada

Evitar:
- excesso de elementos
- poluição visual
- cards exagerados
- excesso de bordas
- excesso de sombras

---

# Botões

Os botões devem:
- parecer premium
- possuir hover suave
- ter animações elegantes
- possuir excelente contraste

Botão principal:
- fundo dourado
- texto preto

Botão secundário:
- transparente
- borda dourada
- texto branco

---

# Animações

Utilizar animações sutis e sofisticadas.

Exemplos:
- fade
- reveal suave
- hover elegante
- transições refinadas

Evitar:
- animações exageradas
- efeitos chamativos demais
- excesso de movimento

---

# Imagens

As imagens devem:
- parecer premium
- possuir alta qualidade
- transmitir sofisticação
- utilizar arquitetura moderna
- possuir composição cinematográfica

Evitar:
- imagens genéricas
- baixa qualidade
- aparência artificial exagerada

---

# Estrutura Visual

O site deve possuir:
- visual clean
- forte hierarquia visual
- excelente contraste
- ótima legibilidade
- aparência moderna

---

# Copy

A copy deve:
- transmitir confiança
- ser clara
- ser objetiva
- ser elegante
- incentivar contato

Evitar:
- textos exagerados
- excesso de formalidade
- promessas irreais

---

# UX

A experiência deve parecer:
- fluida
- premium
- moderna
- intuitiva

O visitante deve entender rapidamente:
- quem é o corretor
- como ele ajuda
- como entrar em contato

---

# Objetivo Final

Criar uma landing page com aparência premium e cinematográfica, transmitindo autoridade, confiança e profissionalismo para gerar contatos via WhatsApp.
