# AI Design Guide — Wanderley Oliveira Imóveis

# Objetivo Visual

Criar uma landing page extremamente premium, sofisticada, elegante e moderna para o corretor de imóveis Wanderley Oliveira.

O design deve transmitir:

- autoridade
- sofisticação
- confiança
- modernidade
- presença profissional
- experiência premium

---

# Direção Estética

A estética do projeto deve seguir:

- dark premium
- minimalismo sofisticado
- luxo moderno
- visual cinematográfico
- composição elegante
- aparência refinada

O site deve parecer desenvolvido por uma agência premium moderna.

---

# Sensação Visual

A experiência visual deve transmitir:

- exclusividade
- impacto visual
- elegância
- profissionalismo
- sofisticação
- confiança

O visitante deve sentir que está vendo:
- uma marca forte
- um corretor profissional
- um serviço de alto nível

---

# Referências Visuais

Inspirar-se visualmente em:

- sites premium de arquitetura
- páginas de imóveis de luxo
- design editorial sofisticado
- interfaces modernas minimalistas
- estética cinematográfica

---

# Estrutura Visual Geral

Utilizar:

- bastante espaço em branco
- grids modernos
- alinhamentos refinados
- hierarquia visual forte
- composição limpa
- elementos sofisticados

Evitar:

- poluição visual
- excesso de informação
- excesso de cards
- excesso de cores
- elementos genéricos

---

# Hero Section

A hero section é a parte mais importante visualmente.

Deve conter:

- imagem full screen de imóvel premium
- overlay preto escuro
- headline forte
- subheadline elegante
- CTA dourado
- foto recortada do corretor
- composição cinematográfica

A hero section deve causar impacto imediato.

---

# Layout do Hero

Estrutura:

Lado esquerdo:
- headline
- subheadline
- CTAs
- informações rápidas

Lado direito:
- foto recortada do corretor

Background:
- imóvel premium ocupando toda a tela

Overlay:
- preto escuro com transparência

---

# Paleta de Cores

## Preto Principal

#000000

Uso:
- fundo principal
- hero
- contraste premium

---

## Dourado

#D1AF66

Uso:
- CTAs
- detalhes
- ícones
- bordas
- destaques sofisticados

---

## Branco

#FFFFFF

Uso:
- títulos
- textos
- contraste
- legibilidade

---

# Tipografia

Utilizar fontes modernas e sofisticadas.

Sugestões:
- Poppins
- Inter

Características:
- excelente legibilidade
- aparência premium
- títulos fortes
- hierarquia visual clara

---

# Botões

Os botões devem parecer premium.

Características:
- grandes
- elegantes
- modernos
- hover refinado
- animações suaves
- excelente contraste

Botão principal:
- dourado
- texto preto

Botão secundário:
- transparente
- borda dourada
- texto branco

---

# Cards

Os cards devem:

- possuir fundo sofisticado
- ter bordas discretas
- aparência premium
- leve transparência
- cantos arredondados
- sombras suaves

Evitar:
- cards exagerados
- excesso de brilho
- visual genérico

---

# Imagens

As imagens devem:

- possuir aparência cinematográfica
- transmitir sofisticação
- ter excelente qualidade
- utilizar imóveis modernos
- apresentar arquitetura elegante

Evitar:
- imagens genéricas
- baixa resolução
- excesso de edição artificial

---

# Responsividade

A versão mobile deve ser extremamente bem trabalhada.

O mobile precisa:
- manter aparência premium
- ter ótima leitura
- preservar hierarquia visual
- possuir excelente espaçamento
- parecer desenhado especificamente para celular

Não apenas adaptado do desktop.

---

# UX

A navegação deve ser:

- fluida
- intuitiva
- elegante
- rápida
- moderna

O visitante deve entender rapidamente:
- quem é o corretor
- como ele ajuda
- como entrar em contato

---

# Animações

Utilizar animações modernas e suaves.

Exemplos:
- fade reveal
- hover elegante
- transições refinadas
- microinterações discretas

Evitar:
- exageros
- animações chamativas
- movimentos excessivos

---

# Objetivo Final

Criar uma landing page cinematográfica, premium e sofisticada que aumente a percepção de valor profissional de Wanderley Oliveira e gere contatos qualificados via WhatsApp.
